# HuntSpawner

S怪自动触发插件，**仍在测试中**，目前仅国服。大部分触发流程还没有完整实测，使用时请留意，遇到问题欢迎反馈。

## 安装

在 Dalamud 的自定义插件仓库中添加以下地址，搜索“S怪触发 HuntSpawner”安装；输入 `/huntspawner`（或 `/hsp`）打开窗口。

```text
https://raw.githubusercontent.com/SAD777A/1010/main/pluginmaster.json
```

## 功能

- **计时**：从 Bear Tracker 读取当前服务器各 S 怪的上次死亡时间（含分线、维护重置），算出冷却、窗口、必出三个阶段；同时显示时间、月相、天气条件什么时候满足。
- **排点**：5.0 以后的踩点类 S 怪先反复打 B，把出现过 A、B 的刷新点排除掉，只踩剩下的点。
- **触发**：到了窗口期自动前往并执行触发动作；点上站着 B 时先打掉再做。
- **提醒**：看到 S 怪出现时在聊天栏和任务提示里提醒，并播放提示音。不会对外发消息。
- **Sonar 联动**（可选）：读取 Sonar 打在聊天栏的报告，用来排点、记录击杀时间。

## 能自动触发的 S 怪

| 方式 | S 怪 |
| --- | --- |
| 舍弃 | 内尤佐缇、俄菲翁尼厄斯、戾虫、盐和光 |
| 踩点 | 南迪、凯撒贝希摩斯、伽马、阿格拉俄珀、布弗鲁、伊努索奇、夺心魔、咕尔呱洛斯、奇里格、兀鲁忽乃朝鲁（要先完成 FATE，按 Bear Tracker 的 FATE 记录判断） |
| 踩点 + 点上动作 | 布隆特斯（吃食物）、多智兽（青魔自爆）、天气预报机器人（青魔狂风暴雪） |
| 击杀计数 | 蚓螈巨虫、卢克洛塔、巨大鳐、优昙婆罗花 |
| 倒地 | 牛头黑神、阿姆斯特朗（青魔，被小怪打死或自爆） |
| 喂怪 | 顾尼图（青魔，把深海水蛭拉给冰海天使吃） |
| 钓鱼 | 千竿口花希达、虚无探索者（调用 MissFisher，可用鱼眼） |
| 采集 | 护土精灵、火愤牛、刚德瑞瓦、得到宽恕的炫学（调用 GatherBuddy Reborn） |
| 制作 | 先驱勇士 阿提卡斯（调用 Artisan） |

**不做**：伊休妲、颇胝迦、沉思之物、努纽努维、神穆尔鸟（按狩猎群约定不碰）。理符、宝图、坠落、运输陆行鸟、FATE 类和狭缝等只计时和提醒，需要手动完成。

## 依赖

- vnavmesh（国服版）：寻路。
- Lifestream：换线。
- 战斗循环插件（如 PromeRotation）：排点、击杀计数时负责输出，本插件只找怪、靠近、选中和开怪。
- 可选：MissFisher（钓鱼）、GatherBuddy Reborn（采集，要先在它的自动采集清单里放好道具）、Artisan（制作）、Sonar（联动）、YesAlready（运行时会暂停它）。

## 用法

1. “S 怪”页列出当前服务器全部 S 怪，鼠标停在名字上看条件、CD 和下次满足时间。
2. 单个目标点“触发”；或点顶部“自动触发”（`/hsp auto`），插件按必出、当前地图、窗口进度挑可自动触发的 S 怪一只只做。`/hsp stop` 停止。目标刷出后自动模式会停下，把时间留给打 S。
3. “设置”页：
   - 舍弃类要先打开“允许舍弃道具”（不可恢复）。
   - 排点、击杀计数要填开怪指令（如 `/ac 飞斧`）并开着战斗循环。
   - 需要切职业的（青魔、捕鱼人、烹调师）可以给每只 S 选套装；阿姆斯特朗要选一套穿着修好的帝国盔帽、短袍的青魔套装。
   - 被小怪打死前可以填一条指令关掉战斗循环，免得自动还手。
4. 鱼粉、填充道具、鱼饵不够时会自动去住宅区商人补买；舍弃用的秧鸡胸脯肉、鸟蛋和布隆特斯的食物会在主城查市场板购买。有单次花费上限。
5. “测试”页可以开测试模式：忽略条件、跳过排点、演练（只显示本应执行什么，不舍弃、不下单、不放技能）。

## 说明

- 隐藏时间点之前完成的条件无效。窗口内没刷出属于正常，插件会按“重试间隔”再来。
- 刷新点坐标取自 wiki；Bear Tracker 是第三方站点，接口不是公开 API，可能随时变化。
- 运行中重载插件前先点停止。
