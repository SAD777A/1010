# HuntSpawner

S怪自动触发插件，**仍在测试中**，支持国服和国际服（同一个安装包，启动时自动选择）。大部分触发流程还没有完整实测，使用时请留意，遇到问题欢迎反馈。

## 安装

在 Dalamud 的自定义插件仓库中添加以下地址，搜索“HuntSpawner”安装；输入 `/huntspawner`（或 `/hsp`）打开窗口。

```text
https://raw.githubusercontent.com/SAD777A/1010/main/pluginmaster.json
```

## 功能

- **计时**：从 Bear Tracker 读取当前服务器各 S 怪的上次死亡时间（含分线、维护重置），算出冷却、窗口、必出三个阶段；同时显示时间、月相、天气条件什么时候满足。
- **排点**：5.0 以后的踩点类 S 怪先反复打 B，把出现过 A、B 的刷新点排除掉，只踩剩下的点。
- **触发**：到了窗口期自动前往并执行触发动作；点上站着 B 时先打掉再做。
- **提醒**：看到 S 怪出现时在聊天栏和任务提示里提醒，并播放提示音。SS 和它的手下单独提醒，不会误当成 S / B。不会对外发消息。
- **Sonar 联动**（可选）：读取 Sonar 打在聊天栏的报告，用来排点、记录击杀时间。

## 能自动触发的 S 怪

| 方式 | S 怪 |
| --- | --- |
| 舍弃 | 内尤佐缇、俄菲翁尼厄斯、戾虫、盐和光 |
| 踩点 | 南迪、凯撒贝希摩斯、伽马、阿格拉俄珀、布弗鲁、伊努索奇、夺心魔、咕尔呱洛斯、奇里格、兀鲁忽乃朝鲁（要先完成 FATE，按 Bear Tracker 的 FATE 记录判断） |
| 踩点 + 点上动作 | 布隆特斯（吃食物）、多智兽（青魔自爆）、天气预报机器人（青魔狂风暴雪） |
| 击杀计数 | 蚓螈巨虫、卢克洛塔、巨大鳐、优昙婆罗花 |
| 倒地 | 牛头黑神、阿姆斯特朗（青魔，被小怪打死或自爆） |
| 喂怪 | 顾尼图（青魔，把深海水蛭拉给冰海天使吃） |
| 钓鱼 | 千竿口花希达、虚无探索者（插件自己钓：在设置里记录钓鱼位置，按拉力提钩，自动拍水、开鱼眼） |
| 采集 | 护土精灵、火愤牛、刚德瑞瓦、得到宽恕的炫学（插件自己采集，自动换采矿工 / 园艺工） |
| 坠落 | 萨法特（在设置里记录起跳点，自动跳崖） |
| 制作 | 先驱勇士 阿提卡斯（调用 Artisan） |

**不做**：伊休妲、颇胝迦、沉思之物、努纽努维、神穆尔鸟（按狩猎群约定不碰）。理符、宝图、运输陆行鸟、FATE 类和狭缝等只计时和提醒，需要手动完成。

## 依赖

- vnavmesh：寻路（国服用国服版）。
- Lifestream：换线。
- 战斗循环插件：排点、击杀计数时负责输出，本插件只找怪、靠近、选中和开怪。装了 BossMod / BossMod Reborn 会自动识别并开关它的预设；其他循环插件（PromeRotation、RSR 等）在设置里填开始 / 关闭战斗指令。
- 可选：Artisan（制作）、Sonar（联动）、YesAlready（运行时会暂停它）。

## 用法

1. “S 怪”页列出当前服务器全部 S 怪，鼠标停在名字上看条件、CD 和下次满足时间。
2. 单个目标点“触发”；或点顶部“自动触发”（`/hsp auto`），插件按必出、当前地图、窗口进度挑可自动触发的 S 怪一只只做。`/hsp stop` 停止。目标刷出后自动模式会停下，把时间留给打 S。
3. “设置”页：
   - 舍弃类要先打开“允许舍弃道具”（不可恢复）。
   - 排点、击杀计数要填开怪指令（如 `/ac 飞斧`）并开着战斗循环。
   - 需要切职业的（青魔、捕鱼人、烹调师）可以给每只 S 选套装；阿姆斯特朗要选一套穿着修好的帝国盔帽、短袍的青魔套装。
   - 被小怪打死前可以填一条指令关掉战斗循环，免得自动还手。
4. 鱼粉、填充道具、鱼饵不够时会自动去住宅区商人补买；舍弃用的秧鸡胸脯肉、鸟蛋和布隆特斯的食物会在主城查市场板购买。有单次花费上限。
5. “测试”页可以开测试模式：忽略条件、跳过排点、演练（只显示本应执行什么，不舍弃、不下单、不放技能）。

## 说明

- 隐藏时间点之前完成的条件无效。窗口内没刷出属于正常，插件会按“重试间隔”再来。
- 刷新点坐标取自 wiki；Bear Tracker 是第三方站点，接口不是公开 API，可能随时变化。
- 运行中重载插件前先点停止。

## 更新日志

### 0.5.0.0

- 识别 SS 和它的手下：出现时单独提醒，不再被当成这张图的 S（误记击杀时间）或 B（干扰排点）。
- 钓鱼改为插件自己完成，不再需要 MissFisher：在“钓鱼 / 采集 / 制作”设置页站在水边、面朝水面记录钓鱼位置。钓法内置（照 MissFisher 预设）：只提鱼王杆，需要时提拍水用的鱼并拍击水面，不在时间段内用鱼眼。

### 0.4.0.0

- 舍弃改为批量处理：一次拆出多份、一起舍弃，不再逐个弹确认框，盐和光这类要舍弃多次的明显加快。
- 新增战斗循环控制（设置“排点与打怪”分页）：开始 / 关闭战斗指令；自动识别 BossMod / BossMod Reborn 并开关所选预设；倒地类拉怪前自动关闭，免得还手。
- 盐和光的填充道具除了材料商的商品，也能选背包里能堆叠、能舍弃的道具（如矮人棉）。

### 0.3.0.0

- 采集改为插件自己完成，不再需要 GatherBuddy Reborn 和清单：按道具自动换采矿工 / 园艺工，飞到采集点采集，并用坚实之心 / 不朽之言、洞察世间增加采集次数。需要有这两个职业的套装。
- 新增萨法特：在“倒地与坠落”设置页站在崖边记录起跳点，插件自动跳崖。
- 设置页拆成多个分页。
- 钓鱼补上演练；测试页列出各类触发在演练时停在哪一步。

### 0.2.0.0

- 双核心：同一个安装包同时支持国服和国际服，启动时按区服自动选择。国际服刚开始测试。
- 修复钓鱼加鱼眼时 MissFisher 报“命令参数有误”。
- 新增“默认触发套装”，以及结束后换回出发前的套装。
- 手动触发时，时间、月相、天气条件要等超过 30 分钟就不出发，直接提示满足时间。
- 击杀计数预置小怪刷怪区域，打 FATE 里的怪前自动等级同步。

### 0.1.0.0

- 首个公开测试版（仅国服）。
