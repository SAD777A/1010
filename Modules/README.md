# LocalName 在线模块

由 1010 维护的 Chrysalism 单文件模块，当前版本 0.2.44.13。模块列表、内部设置页及功能核心版本一致，和独立插件使用同一套功能源码。

## 安装与更新

在 Chrysalism 的在线模块库中添加以下清单地址，刷新后下载或更新 LocalName，再手动启用：

```text
https://raw.githubusercontent.com/SAD777A/1010/main/ChrysalismModules.json
```

也可添加仓库地址 https://github.com/SAD777A/1010。启用前停用独立版 LocalName，并关闭 Chrysalism 的自定义名称，避免冲突。此清单供 Chrysalism 使用，不是卫月插件仓库清单。

LocalName.cs 内嵌国服、国际服程序与素材，首次下载可能需要一些时间。请完整下载，不要删改文件末尾的资源。在线加载器按清单 SHA256 校验整个文件。独立插件与 cs 模块分开打包、分别更新。
