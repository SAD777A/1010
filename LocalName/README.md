# LocalName

一个修改本地名字等显示的小玩具，并添加了一些特效

作者：1010 · 当前版本：0.2.21 · **开发测试中**

## 安装

在 Dalamud 的自定义插件仓库中添加以下地址，搜索“本地改名 LocalName”安装；输入 `/localname` 打开设置。已有用户在插件安装器中检查更新。

```text
https://raw.githubusercontent.com/SAD777A/1010/main/pluginmaster.json
```

## 能做什么

- **文字替换**：修改自己的本地名字、区服、称号和部队后缀；覆盖头顶、聊天、部分游戏界面、冒险者铭牌，以及已识别的宠物、召唤物和雇员主人标签。只影响本机显示，其他玩家看到的资料不变。
- **头顶外观**：配色、描边、彩虹、流光、扫光，以及打字机、光标、称号轮播等文字动画。其他界面只替换文字；神光同步可统一名字、称号和后缀的配色，关闭后恢复分项设置。
- **像素装饰**：阳光彩虹小白马、青鸟与音符、职业图标方块小人、滚动猫小胖、蹦跳摩艾石像。可单独选择，或用“＋”组成不重复的自定义组合；支持速度、大小、间距调整。
- **新增宠物动作**：猫小胖慢速向左侧滚，到端点转身滚回，完整来回后休息约 3 秒；摩艾往返蹦跳并在两端转向。可在“装饰”页选择。
- **独立名字尾饰**：导入本地 PNG/JPG/GIF 图片，动图保留动画；跟随名字或后缀末尾，可调整大小、间距、上下偏移和透明度，与头顶装饰同时使用。
- **本地外观预设**：保存配色、文字动画和装饰，支持命名、同名更新确认、导入、导出、删除和恢复套用前；预设不包含名字、称号内容、区服或本地图片路径。

## 怎么设置

主界面分为“文字 / 外观 / 装饰 / 高级”，高级设置只有一个入口。内容在窗口内滚动，数值直接输入；鼠标悬停可看详细说明。

“选择预设”打开独立窗口，先预览，再点“套用并关闭”；“保存当前”保存为本地预设。“无”关闭对应效果；顶部“暂停特效”暂时隐藏特效并保留参数；“恢复外观默认”重置外观，保留文字、本地图片和已保存预设。

默认进入副本后隐藏特效、保留文字替换，离开副本后恢复；可通过“副本内隐藏特效”开关调整。

## 配置与适配

新安装使用空白文字、默认不开启配色、动画或装饰；名字留空就显示当前角色的游戏原名，称号和后缀可独立设置。更新保留已有配置，不自动读取其他插件设置。个人配置、导入图片和保存的预设只在本机，不上传，也不随安装包分发；仓库仅提供运行文件和说明。

国服与国际服使用同一个安装包，按宿主依赖选择对应模块。当前为 **Dalamud API 15**：
