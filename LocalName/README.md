# LocalName

一个修改本地名字等显示的小玩具，并添加了一些特效

作者：1010 · 当前版本：0.2.14.1 · **开发测试中**

## 安装

在 Dalamud 的自定义插件仓库中添加：

```text
https://raw.githubusercontent.com/SAD777A/1010/main/pluginmaster.json
```

搜索“本地改名 LocalName”并安装，输入 `/localname` 打开设置。

新安装从空白设置开始。名字留空时显示当前角色的游戏原名，称号和后缀仍可单独修改。不预填个人文字，不自动读取其他插件设置；已有用户的设置继续保留。

## 功能

- 修改自己的本地名字、区服、称号和部队后缀显示，其他玩家看到的资料不变。
- 替换聊天、部分游戏界面、冒险者铭牌以及已识别的宠物、召唤物和雇员主人标签；按界面识别自己的文字。
- 自己头顶支持彩虹、流光、扫光等配色，以及打字机、称号轮播等文字动画。其他地方只替换文字。
- 神光同步让名字、称号和后缀共用配色，关闭后恢复各自设置。
- 像素风青鸟与音符、职业方块小人、阳光彩虹小白马等头顶装饰。
- 独立尾饰支持本地 PNG/JPG/GIF，可与头顶装饰同时开启。图片只保存在本机，不上传，也不随插件分发；GIF 保留原动画。
- 默认进入副本后隐藏特效，保留文字替换，离开副本后恢复。

## 设置

四个页面：文字、配色与动画、装饰、更多。
速度、大小、间距等数值直接输入，回车或点到别处后保存；详细用途和调整方向可将鼠标停在选项上查看。
