# LocalName

一个修改本地名字等显示的小玩具，并添加了一些特效

作者：1010 · 当前版本：0.2.26 · **开发测试中**

## 安装

在 Dalamud 的自定义插件仓库中添加以下地址，搜索“本地改名 LocalName”安装；输入 `/localname` 打开设置。已有用户在插件安装器中检查更新，仓库地址不变。

```text
https://raw.githubusercontent.com/SAD777A/1010/main/pluginmaster.json
```

## 能做什么

- **文字替换**：修改自己的本地名字、区服、称号和部队后缀；覆盖头顶、聊天、部分游戏界面、冒险者铭牌，以及已识别的宠物、召唤物和雇员主人标签。只影响本机显示，别人看到的资料不变。
- **头顶外观**：配色、描边、彩虹、流光、扫光，以及名字、称号、后缀各自的打字机、光标、轮播等文字动画。其他界面只替换文字。颜色与特效各自支持同步设置或分别设置，切回分别设置恢复原参数；轮播文字分别保留。
- **16 套内置配色**：保留终端霓虹、冰蓝极光、鎏金扫光、粉紫星云、阳光彩虹，新增红、橙、黄、绿、青、蓝、紫、粉、黑、白、灰各一套。
- **像素装饰**：阳光彩虹小白马、青鸟与音符、职业图标方块小人、滚动猫小胖、蹦跳摩艾石像。猫小胖侧滚往返后休息，摩艾在两端转向；支持速度、0.5～3 倍大小、间距调整，可用“＋”组合不同装饰。各角色在 1 倍时主体高度接近，保留各自比例与自然动作；星星、彩虹等点缀保留相对比例，尾饰单独调整。
- **独立名字尾饰**：导入本地 PNG/JPG/GIF，保留透明背景和动图动画；跟随名字或后缀末尾，可调大小、间距、上下偏移和透明度，与头顶装饰同时使用。
- **本地预设**：保存和套用可选仅外观、仅文字或两者。外观页选中即可套用，在下方微调后保存修改或另存；支持撤销上次套用、重命名、同名覆盖确认、导入导出和删除。旧版预设继续视为仅外观。
- **职业自动套用**：在主窗口“职业套用”页为各职业指定预设与范围，规则按角色保存；职业按坦克、治疗、近战、远敏、法系排列。切换职业时套用一次；登录、刚开启或保存规则时不立即套用，没有规则的职业保持当前设置。

## 怎么设置

主界面分为“文字 / 外观 / 装饰 / 职业套用 / 高级”。外观页选中预设即可套用，下方分为颜色、特效两区，各自选择同步设置或分别设置；仅在分别设置时选择名字、称号或后缀。更多颜色和效果细节按需展开。预设管理使用独立窗口，只显示“我的预设”；内置配色仍在外观页和职业套用的选择列表中。外观和装饰页底部提供“应用”与“保存到预设…”，分别确认当前设置和保存命名预设。内容在窗口内滚动，数值直接输入，鼠标悬停查看说明。

颜色特效选“无”保留静态配色，文字效果选“无”显示完整文字；取消“自定义颜色”使用游戏原色，描边可单独关闭；“暂停特效”暂时隐藏特效并保留参数；“恢复外观默认”重置外观，保留文字、本地图片和已保存预设。默认进入副本后隐藏特效、保留文字替换，出本后恢复，也可关闭此选项。

保存与导出会保留两组同步模式、共享参数及分项参数。支持导入旧预设；新版预设需要0.2.25及后续支持该格式的版本读取。

导出预设时自动保存 JSON，通过“打开导出文件夹”取文件。导出包含预设已保存的全部内容：含文字的预设会包含对应文字，不包含本地图片路径或职业规则。

## 配置与适配

新安装使用空白文字，默认不开配色、动画或装饰；名字留空显示游戏原名。更新保留已有配置，不自动读取其他插件设置。个人设置、图片和预设只存在本机，不自动上传，也不随安装包分发。插件未加入用户加载统计。

国服与国际服使用同一个安装包，按宿主依赖选择对应模块。当前为 **Dalamud API 15**：

游戏或 Dalamud 更新后可能需要更新插件。开发测试中。
