# LocalName

一个修改本地名字等显示的小玩具，并添加了一些特效

作者：1010 · 当前版本：0.2.33.2 · **开发测试中**

## 安装

在 Dalamud 的自定义插件仓库中添加以下地址，搜索“本地改名 LocalName”安装；输入 `/localname` 打开设置。已有用户在插件安装器中检查更新，仓库地址不变。

```text
https://raw.githubusercontent.com/SAD777A/1010/main/pluginmaster.json
```

## 能做什么

- **文字替换**：修改自己的本地名字、区服、称号和部队后缀；覆盖头顶、聊天、部分游戏界面、冒险者铭牌，以及已识别的宠物、召唤物和雇员主人标签。只影响本机显示，别人看到的资料不变。
- **头顶外观**：配色、描边、彩虹、流光、扫光，以及名字、称号、后缀各自的打字机、光标、轮播、逐字点亮、星点闪耀与渐变轮播等文字动画。其他界面只替换文字。颜色与特效各自支持同步设置或分别设置，切回分别设置恢复原参数；轮播文字分别保留。
- **16 套内置配色**：保留终端霓虹、冰蓝极光、鎏金扫光、粉紫星云、阳光彩虹，新增红、橙、黄、绿、青、蓝、紫、粉、黑、白、灰各一套。
- **头顶装饰**：阳光彩虹小白马、青鸟与音符、职业方块小人、滚动猫小胖、蹦跳摩艾石像。猫小胖侧滚往返后休息，摩艾在两端转向；支持速度、0.5～3 倍大小、间距调整，可用“＋”组合不同装饰。各角色在 1 倍时主体高度接近，保留各自比例与自然动作；星星、彩虹等点缀保留相对比例，尾饰单独调整。
- **名字前职业图标**：只调整自己的图标，提供默认（金色）、彩底金框、发光三种样式，可调大小与间距，随职业切换。彩底金框使用小号素材；关闭开关恢复原样并保留参数。使用前请关闭 Party Icons，检测到它运行时暂停图标替换。
- **职业小人**：内置 A/B 两组共 41 张原画素材，保留配件。A 组按角色走动、跑动、蹦跳或平移，B 组全部平移，回程转身。可跟随当前职业或固定职业；支持逐职业混搭 A/B、导入本地 PNG/GIF，缺少的职业或本地图片会回退到可用的内置素材。自定义图片平移，GIF 保留原动画。
- **独立名字尾饰**：导入本地 PNG/JPG/GIF，保留透明背景和动图动画；跟随名字或后缀末尾，可调大小、间距、上下偏移和透明度，与头顶装饰同时使用。
- **本地预设**：保存和套用可选仅外观、仅文字或两者。外观页选中即可套用，微调后通过“保存预设…”更新当前预设或另存；支持撤销上次套用、重命名、同名覆盖确认、导入导出和删除。旧版预设继续视为仅外观。
- **副本与死亡状态**：副本内外分别设置“常规特效”和“死亡黑白特效”，均可启用或不启用。死亡黑白包含名字、称号、部队后缀、描边和职业图标，文字与配色动画暂停，复活后恢复当前区域设置；宠物和尾饰不参与黑白。
- **职业自动套用**：在主窗口“职业套用”页为各职业指定预设与范围，规则按角色保存；职业按坦克、治疗、近战、远敏、法系排列。切换职业时套用一次；登录、刚开启或保存规则时不立即套用，没有规则的职业保持当前设置。

## 怎么设置

主界面分为“文字 / 外观 / 装饰 / 职业套用 / 高级”，内容在窗口内滚动，鼠标悬停查看说明。界面采用淡银色背景水印与紧凑布局，拖动窗口边缘可调整大小。

- **外观**：选中预设即可套用。颜色、特效各自选择“同步设置 / 分别设置”；分别设置时再选名字、称号或后缀。点击色块打开调色器，描边与效果细节按需展开。
- **新文字效果**：外观页的“文字效果”中选择逐字点亮、星点闪耀或渐变轮播；先开启自定义颜色。逐字点亮保留完整文字、依次变亮，长文字可能合并为几组；星点闪耀让文字零星闪亮；渐变轮播在换字时淡出、淡入，沿用“轮播内容”，每条时长包含渐变时间。颜色特效仍可叠加，鼠标悬停查看说明。
- **装饰**：常用大小、速度直接调整；间距、透明度等收在“位置与细节”。两页共用可收起的完整名牌预览，外观页预览位于上方，字体和位置供参考。
- **名字前图标**：装饰页顶部勾选“启用职业图标”，再选样式，在“大小与间距”中调整；在角色头顶查看效果。设置也会随外观预设保存。
- **高级**：在“副本外 / 副本内”两行分别选择“常规特效 / 死亡黑白特效”的启用状态，下方实时解释两处规则及当前状态。常规特效不启用时仍保留文字替换，也能单独启用死亡黑白；不会因此开启装饰或其他动画。“文字替换范围”和“兼容与运行状态”按需展开。
- **小人自定义**：装饰页选择“职业方块小人”，在“素材”中选 A/B 默认组；点“自定义…”给各职业单独选组或本地图片。没有单独设置的职业继续跟随默认组，所有修改自动保存。
- **保存**：外观和装饰自动保存；“保存预设…”统一提供更新当前预设、另存为新预设。更新只写回这份预设已有范围内改过的部分，内置配色请另存。文字页仍点“应用文字”，轮播列表点“应用轮播列表”，避免输入一半就替换。
- **预设管理**：独立窗口只显示“我的预设”；内置配色留在外观页和职业套用的选择列表。含文字与外观的预设可选择套用范围。

颜色特效选“无”保留静态配色，文字效果选“无”显示完整文字；取消“自定义颜色”使用游戏原色，描边可单独关闭；“暂停特效”暂停所有外观效果（包括职业图标替换和死亡黑白）并保留参数；高级页的“恢复外观默认”重置外观，保留文字、本地图片和已保存预设。新安装默认副本外启用常规特效、副本内不启用，死亡黑白均不启用；更新沿用原来的副本设置。副本内外规则保存在本地，不随预设或职业套用改变；恢复外观默认会关闭死亡黑白，保留两处常规特效选择。

保存与导出会保留两组同步模式、共享参数及分项参数。支持导入旧预设；含职业小人选项的预设需使用 0.2.28 或更新版本；含新文字效果的预设需使用 0.2.30 或更新版本，含职业图标设置的预设建议使用 0.2.32 或更新版本。

导出预设时自动保存 JSON，通过“打开导出文件夹”取文件。导出包含预设已保存的全部内容：含文字的预设会包含对应文字，不包含本地图片及路径或职业自动套用规则。小人的 A/B 组与按职业选择会保留；收到使用本地图片的预设后，需要在自己的电脑上选择图片。

## 配置与适配

新安装使用空白文字，默认不开配色、动画或装饰；名字留空显示游戏原名。更新保留已有配置，不自动读取其他插件设置。个人设置、图片和预设只存在本机，不自动上传，也不随安装包分发。插件未加入用户加载统计。

国服与国际服使用同一个安装包，按宿主依赖选择对应模块。当前为 **Dalamud API 15**：
