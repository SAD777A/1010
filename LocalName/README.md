# LocalName

## 安装

在 Dalamud 的自定义插件仓库中添加以下地址，搜索“本地改名 LocalName”安装；输入 `/localname` 打开设置。已有用户在插件安装器中检查更新，仓库地址不变。

```text
https://raw.githubusercontent.com/SAD777A/1010/main/pluginmaster.json
```
