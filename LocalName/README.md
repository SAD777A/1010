# LocalName

一个修改本地名字等显示的小玩具，并添加了一些特效

## 安装

在 Dalamud 的自定义插件仓库中添加：

```text
https://raw.githubusercontent.com/SAD777A/1010/main/pluginmaster.json
```

搜索“本地改名 LocalName”并安装，使用 `/localname` 打开设置。
从开发插件版本迁移时，先停用旧 LocalName 及旧路径的自动加载，再安装仓库版。两服使用同一个安装包，各自保留设置。

[直接下载安装包](https://raw.githubusercontent.com/SAD777A/1010/main/LocalName/LocalName.zip)

## 功能

- 修改自己的本地姓名、区服、已有称号及头顶部队后缀显示。
- 覆盖聊天、部分原生界面、自己的冒险者铭牌和已识别的宠物/召唤物主人标签等位置；各界面的匹配方式不同，不保证所有位置均已覆盖。
- 自己头顶可选固定颜色、彩虹、双色流光、扫光、呼吸辉光、三色极光、往返扫光和静态渐变。其他位置仅替换文字。
- 不改变服务器上的真实角色身份或其他玩家看到的资料。

版本 0.2.7，Dalamud API 15。

| 国际服 | 15.0.3.6-30-g67e514cac | 7.56.2.9248 |

统一入口根据宿主依赖版本选择内置模块。未适配的版本会停止加载并提示版本信息；游戏或 Dalamud 更新后可能需要更新插件。

双服各250项功能检查、19项统一入口兼容检查通过。当前包已完成离线验证，实际游戏内显示、动画与其他插件共存仍待进一步测试。长文字可能减少渐变分段或回退纯文字，以控制姓名牌编码长度。

DR 文本替换、Honorific 等插件若同时修改相同名字/称号/后缀，可能互相覆盖；避免重叠的替换规则。Party Icons 的实际共存效果也需按使用场景验证。

头顶称号更新阶段参考 [Honorific](https://github.com/Caraxi/Honorific) 的处理思路独立实现，不依赖安装 Honorific。
