# MarkHunter

自动刷 B 级恶名精英。仅支持国服。

- **刷数量**：在一张图里反复刷 B 级怪，攒成就“英名远播的B级精英杀手”（击杀 1000 只）。
- **刷种类**：按地区轮换地图，每种 B 级怪打一只，完成讨伐 N 种 B 级的地区成就（新生 4 个、苍穹 2 个、红莲 2 个），已完成的自动跳过。

## 安装

在 Dalamud 的自定义插件仓库中添加以下地址，搜索“B怪猎手 MarkHunter”安装；输入 `/markhunter` 打开窗口。

```text
https://raw.githubusercontent.com/SAD777A/1010/main/pluginmaster.json
```

## 依赖

- vnavmesh（国服版）：负责寻路。
- 战斗循环插件（如 PromeRotation）：负责输出，本插件不打技能。
- Lifestream（可选）：去龙堡内陆低地要从田园郡走城内以太水晶网，没装就步行出城。

## 用法

1. “模式”页选刷数量（选地图）或刷种类（勾选地区）。
2. “战斗”页填开怪指令（如 `/ac 飞斧`），按职业设置战斗距离（近战 3，远程 20 左右）。
3. 打开战斗循环，点“开始”或输入 `/markhunter start`；`/markhunter stop` 停止。

## 说明

- 侦测半径推荐：刷数量 90 米，刷种类 50–60 米（2.0 的图空气墙多，半径大了容易撞墙）。
- 飞行要先解锁对应地图的飞行；没解锁就关掉“飞行”。
- 讨伐按仇恨计算，开怪后要打出仇恨才算数。
- 刷新点坐标来自 Console Games Wiki。
- 运行中重载插件前先点停止，否则 vnavmesh 可能继续执行停止前的路线。
